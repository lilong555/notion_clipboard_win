这里是因为我们令了

[
r=de.
]

既然

[
r=de,
]

而 (e) 是正整数，所以 (r) 一定是 (d) 的倍数，也就是

[
d\mid r.
]

这就是为什么内层会变成 (d\mid r)。

原式是

[
\sum_{d\mid n}\mu(d)\tau\left(\frac nd\right).
]

因为

# [

\tau\left(\frac nd\right)

\sum_{e\mid \frac nd}1,
]

所以

# [

\sum_{d\mid n}\mu(d)\tau\left(\frac nd\right)

\sum_{d\mid n}\mu(d)
\sum_{e\mid \frac nd}1.
]

这表示对所有满足

[
d\mid n,\qquad e\mid \frac nd
]

的二元组 ((d,e)) 求和。

注意：

[
e\mid \frac nd
]

说明存在整数 (q)，使得

[
\frac nd=eq.
]

两边乘 (d)，得到

[
n=deq.
]

所以

[
de\mid n.
]

于是令

[
r=de,
]

就有

[
r\mid n.
]

同时因为

[
r=de,
]

所以

[
d\mid r.
]

因此原来的条件

[
d\mid n,\qquad e\mid \frac nd
]

可以改成

[
r\mid n,\qquad d\mid r.
]
