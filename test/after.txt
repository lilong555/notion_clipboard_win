对，这题正解就是：SCC 缩点成 DAG，然后在 DAG 上做最大路径和 DP。

原因是：

在一个强连通分量 SCC 里面，任意两个点互相可达，所以你一旦进入这个 SCC，就可以把这个 SCC 里的所有房间金币都拿完。因此可以把一个 SCC 看成一个“超级点”，它的权值是这个 SCC 内所有房间金币之和。

缩点后图一定是 DAG，因为如果缩点后还有环，那这些 SCC 本来就应该属于同一个 SCC。

然后问题变成：

在一个 DAG 上，每个点有权值，任选起点和终点，求一条路径上点权和最大值。

DP 即可。

定义：

```

```

dp[u] = 以缩点后的点 u 结尾时，最多能收集多少金币

```

```

如果 DAG 边为 u -> v，那么：

```

```

dp[v] = max(dp[v], dp[u] + sum[v])

```

```

初始化：

```

```

dp[u] = sum[u]

```

```

答案：

```

```

max(dp[u])

```

```

也可以反过来定义：

```

```

dp[u] = 从 u 出发最多能收集多少金币

```

```

然后对边 u -> v：

```

```

dp[u] = max(dp[u], sum[u] + dp[v])

```

```

这种写法需要按拓扑序反向处理。

复杂度：

```

```

Tarjan/Kosaraju SCC: O(n + m)
建 DAG: O(n + m)
DAG DP: O(n + m)

```

```

注意金币最多是：

```

```

1e5 * 1e9 = 1e14

```

```

所以必须用 long long。

样例里：

房间 1 和 2 互相可达，缩成一个点，金币为 4 + 5 = 9。

从这个 SCC 可以去 3 或 4，其中去 4 得到：

```

```

9 + 7 = 16

```

```

所以答案是 16。
