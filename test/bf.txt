可以用 **KMP 自动机 + 树 DFS** 写，关键观察是：

一个答案 pair `(start position, end position)` 对应的字符串长度固定为 `|t|`，所以 **只要确定结束位置，开始位置就唯一确定**。
因此题目等价于：

> 对树上所有从根往下走时经过的字符位置，统计有多少个位置作为结尾时，根到该位置的路径后缀等于 `t`。

也就是在树上的每条根到节点路径上跑模式串匹配。

---

## 思路

设 `m = |t|`。

我们对 `t` 建 KMP 自动机 `go[state][c]`：

* `state` 表示当前已经匹配了 `t` 的前 `state` 个字符；
* 读入字符 `c` 后，转移到 `go[state][c]`；
* 如果转移后 `state == m`，说明有一个 `t` 在当前位置结尾，答案加一。

树边上是字符串，所以 DFS 时：

从父节点继承当前 KMP 状态，沿着这条边的字符串一个字符一个字符转移，扫完后把新状态传给子节点。

因为总字符数最多 `3 * 10^5`，所以这样是可以的。

---

## 复杂度

建自动机：

```text
O(26 * |t|)
```

扫描所有边字符串：

```text
O(总字符数)
```

总复杂度：

```text
O(26 * |t| + 总字符数)
```

## C++ 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<vector<pair<int, string>>> g(n + 1);

    for (int v = 2; v <= n; v++) {
        int p;
        string s;
        cin >> p >> s;
        g[p].push_back({v, s});
    }

    string t;
    cin >> t;

    int m = (int)t.size();

    // KMP prefix function
    vector<int> pi(m, 0);
    for (int i = 1; i < m; i++) {
        int j = pi[i - 1];
        while (j > 0 && t[i] != t[j]) {
            j = pi[j - 1];
        }
        if (t[i] == t[j]) {
            j++;
        }
        pi[i] = j;
    }

    // KMP automaton
    vector<array<int, 26>> go(m + 1);

    for (int state = 0; state <= m; state++) {
        for (int c = 0; c < 26; c++) {
            if (state < m && c == t[state] - 'a') {
                go[state][c] = state + 1;
            } else {
                if (state == 0) {
                    go[state][c] = 0;
                } else {
                    go[state][c] = go[pi[state - 1]][c];
                }
            }
        }
    }

    long long ans = 0;

    // iterative DFS: vertex, current KMP state
    vector<pair<int, int>> st;
    st.push_back({1, 0});

    while (!st.empty()) {
        auto [v, state] = st.back();
        st.pop_back();

        for (auto &[to, s] : g[v]) {
            int cur = state;

            for (char ch : s) {
                cur = go[cur][ch - 'a'];

                if (cur == m) {
                    ans++;
                }
            }

            st.push_back({to, cur});
        }
    }

    cout << ans << '\n';

    return 0;
}
```

---

## 为什么这样不会漏？

比如某个位置作为结尾，如果它前面连续向上数 `|t|` 个字符正好是 `t`，那么 KMP 状态一定会在这里变成 `|t|`。

而一个结束位置最多只对应一个长度为 `|t|` 的起始位置，所以每次 `cur == m` 时加一，正好对应一个合法 pair。
